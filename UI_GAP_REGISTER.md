# UI Gap Register — عسلكم

## قاعدة التسجيل

يُسجل هنا كل تعارض أو نقص يمنع تنفيذ UI مدعومًا بالبيانات أو الصلاحيات. لا تُحل الفجوة بإضافة Fake Data أو Mock Success أو تغيير Schema تلقائيًا. الحالات المستخدمة هي `OPEN`, `IN_PROGRESS`, `BLOCKED`, `RESOLVED`.
