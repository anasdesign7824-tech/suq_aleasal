0. قاعدة البداية الصفرية — ZERO-ASSUMPTION GREENFIELD RULE
============================================================

ابدأ من الصفر.

لا تفترض وجود:
- مستودع سابق.
- تطبيق سابق.
- كود سابق.
- OSMEA.
- Storefront.
- StoreMollie.
- WooCommerce.
- Shopify.
- MasterFabric.
- أي قالب تجارة إلكترونية سابق.
- أي Design System سابق.
- أي قاعدة بيانات سابقة.
- أي API سابق.
- أي نموذج بيانات سابق.

لا تحاول إعادة بناء منتج سابق.

لا تبحث عن حلول في مشاريع قديمة لمجرد أنها موجودة في البيئة.

لا تنسخ معماريات جاهزة من مشروع سابق.

لا تستخدم أسماء أو مفاهيم أو semantics مرتبطة بمتجر إلكتروني تقليدي.

أنشئ المنتج باعتباره Greenfield Product حقيقيًا.

إذا كانت هناك خدمات خارجية متصلة ببيئة التنفيذ مثل:
- GitHub
- Supabase
- Cloudflare
- APIs
- local development environment

فهي أدوات بنية تحتية متاحة لك، وليست مصدرًا لفكرة المنتج أو معماريته.

ابدأ المشروع والكود والهيكل من الصفر.

أنشئ مستودع Git جديدًا للمشروع عند الحاجة.
أنشئ مشروع Flutter جديدًا عند الحاجة.
أنشئ بنية Web Admin جديدة.
أنشئ Landing Website جديدًا.
أنشئ Database schema جديدًا.
أنشئ API/data contracts جديدة.

لا تستورد مشروعًا قديمًا لتعديله.
