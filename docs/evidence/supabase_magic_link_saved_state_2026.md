# إثبات حفظ قالب Magic link or OTP

**التاريخ:** 17 أغسطس 2026

تم تعديل قالب `Authentication → Emails → Magic link or OTP` في مشروع Supabase production وحفظه بعد تأكيد المستخدم.

الحالة الظاهرة بعد الضغط على Save changes:

- Subject: `رمز الدخول إلى حسابك — عسلكم`
- Body يبدأ بقالب HTML العربي بهوية عسلكم.
- جسم الرسالة يحتوي على `{{ .Token }}` فقط كرمز رقمي.
- لا يحتوي جسم الرسالة على `{{ .ConfirmationURL }}` أو رابط `<a href>`.
- زر Save changes عاد إلى حالته الطبيعية بعد الحفظ.

سيتم إعادة تحميل صفحة القالب للتحقق من بقاء هذه القيم بعد انتهاء عملية الحفظ.

بدأت إعادة تحميل صفحة Magic link or OTP بعد الحفظ الثاني للتحقق من الثبات. سيتم تسجيل محتوى المحرر بعد اكتمال التحميل.

تمت إعادة تحميل الصفحة بعد الحفظ اليدوي، وظهر محرر Magic link or OTP بالمصدر العربي الكامل، Subject: `رمز الدخول إلى حسابك — عسلكم`، مع `{{ .Token }}` داخل القالب وعدم ظهور قالب الرابط القديم. هذا يؤكد ثبات التعديل بعد إعادة التحميل.
