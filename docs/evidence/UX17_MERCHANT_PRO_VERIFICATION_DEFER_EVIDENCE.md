# UX-17 — تأجيل Pro والتوثيق من واجهة التاجر

بناءً على التوجيه التنفيذي الأخير، أُخفيت عناصر Pro والتوثيق والخطط من `MerchantDashboard` فقط: أزيلت بطاقة توثيق Pro، ورسالة انتظار الباقة، وزرا طلب التوثيق وإدارة الخطة. بقيت شاشات التوثيق والخطط، والـ DTOs، والجداول، وعمليات الإدارة والـ backend دون حذف؛ يمكن إعادة إظهارها لاحقًا بقرار واجهة مستقل دون إعادة بناء المسار الخلفي.

بقيت حالة المتجر وبياناته الأساسية، ومحرر بيانات المتجر والصور، والطلبات، والكتالوج، والتفاعل، والدعم. لم تُخفَ بيانات الخطة داخل العقود أو المستودعات، ولم تُستخدم أي إزالة schema كحل تجميلي.

التحقق: `flutter analyze` بنتيجة `No issues found!`، واختبار `merchant_analytics_widget_test.dart` نجح مع assertions صريحة على غياب نصوص `توثيق Pro` وأزرار الخطط والتوثيق.
