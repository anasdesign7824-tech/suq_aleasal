# دليل TASK 064 — سجل التدقيق في لوحة الإدارة

**التاريخ:** 24 أغسطس 2026

**النطاق:** مراجعة قراءة أثر الأفعال الإدارية وعرض المنفذ والكيان والزمن، مع إبقاء مسار السجل المصدرّي وصلاحيات القراءة دون تغيير.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 064 بـ`AdminGovernance.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/064_admin_audit_log.png` و`explanations/064_admin_audit_log.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يعرض `AuditPanel` الأفعال والكيانات ويقرأها عبر `adminApi.auditLogs`. كُشف أن خطأ القراءة يظهر نصًا بلا إجراء retry واضح، وأن الصف يعرض الفعل والكيان والزمن فقط رغم أن payload يوفّر `entity_id` و`actor_user_id`. أضيف زر إعادة المحاولة داخل حالة الخطأ، ووسم وصول لتحديث السجل، وعرض معرف الكيان والمنفذ عند توفرهما. بقيت دوال labels والتوقيت ومسار API وبيانات السجل كما هي.

لم تُنشأ سجلات أو تغييرات DB، ولم تُخفَ البيانات الحساسة خلف قيم مخترعة؛ عند غياب المعرف لا يظهر placeholder مضلل.

## بوابات الإثبات

| البوابة | النتيجة |
|---|---|
| `pnpm test` | PASS — 8 ملفات اختبار قائمة |
| `pnpm check` | PASS — `tsc --noEmit` |
| `pnpm build` | PASS — Vite وesbuild؛ تحذير chunk أكبر من 500 kB بقي تحذير أداء |
| مراجعة audit path | PASS — loading/error/retry/empty/action/entity labels/entity id/actor id/timestamp |

النتيجة المهيكلة محفوظة في `artifacts/task064_admin_audit_log_result.json`.

## الحدود والقرار

لم تُجرَ كتابة أو قراءة Production حية من خلال جلسة اعتماد، ولم تُشغّل مقارنة golden لغياب Markdown وPNG. لا يُدّعى اكتمال retention أو تصدير السجل أو فلاتره الزمنية ما لم يكن ذلك ضمن العقد القائم.

**قرار TASK 064:** PASS للتعديل الوظيفي المحدود والبناء والاختبارات، مع GAP-038 لفقدان أصول التدقيق البصرية/السلوكية. لا تغيير DB/API/RLS/الصلاحيات.
