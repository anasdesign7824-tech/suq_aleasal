## Contract decision

يجب أن تستمر الواجهة في عرض empty/partial states عندما لا تعيد البيانات نتائج، وألا تضيف منتجات أو متاجر وهمية لتعويض ندرة البيانات. مسار التطبيق المعتمد يبقى UI → ViewModel/Controller → Repository Interface → ProductionRepository → Supabase، مع إبقاء Service Role خارج العميل.

## Remaining production gates

يلزم قبل إعلان الإصدار النهائي إكمال اختبارات المصادقة الحقيقية ببريد اختبار، اختبار الكتابة بصلاحيات المستخدمين، فحص Storage/RLS/Realtime، معالجة regression/golden، وتثبيت artifact ورابط توزيع عام معتمد.
