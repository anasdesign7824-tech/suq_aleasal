# دليل TASK 057 — طلبات التجار في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** مراجعة قائمة طلبات التجار ومسار قرار الإدارة، مع إبقاء تفعيل المتجر والإشعار عبر المسار القائم وعدم إدخال write حي.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 057 بـ`AdminMerchantApplications.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/057_admin_merchant_requests.png` و`explanations/057_admin_merchant_requests.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يعرض `AdminMerchantApplicationsPanel` حالات التحميل والخطأ والفراغ والتحديث، ويستخدم `AdminSafeImage`، ويعرض الاسم والهاتف والموقع والخبرة والتخصصات والملاحظة والحالة. الأفعال قبل الاعتماد هي تفعيل المتجر أو طلب معلومات إضافية أو الرفض، بينما الحالة المعتمدة تعرض نتيجة القرار ولا تعيد أزرارًا مكررة. كل قرار يستدعي `adminApi.reviewMerchantApplication` الحقيقي ويعيد تحميل القائمة بعد النجاح.

كان من الممكن النقر المتكرر على القرار قبل اكتمال الطلب، كما أن الرفض/التفعيل/طلب المعلومات أفعال ذات أثر يستحسن تأكيدها. عولج ذلك بإضافة `reviewingId` لكل طلب، guard، confirmation عربي مخصص للفعل، وتعطيل الأزرار أثناء الحفظ. بقيت رسالة النجاح مرتبطة بالمسار القائم، ولم تُضف مزامنة أو إشعارًا خارج ما يعيده المصدر.

## الحدود والقرار

لم يُعتمد طلب تاجر حي ولم تُرسل إشعارات فعلية خلال المهمة، ولم تُشغّل مقارنة golden لغياب Markdown وPNG. لا يُدّعى تفعيل متجر أو مزامنة بين جهازين؛ ذلك يحتاج جلسة Admin وحسابًا آمنًا واختبارًا قابلًا لإعادة الإنتاج.
