# دليل TASK 054 — إدارة المتاجر في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** مراجعة قائمة المتاجر ومسارات الحالة والتفاصيل والمراجعة في Admin، دون تنفيذ تعديل حي أو تغيير DB/API/RLS/الصلاحيات.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 054 بـ`Home.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/054_admin_stores.png` و`explanations/054_admin_stores.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد المصدرّي

يستخدم `StoresPanel` قائمة `adminApi.stores` مع حالات التحميل والخطأ والفراغ والتحديث. لكل متجر صورة شعار أو غلاف مع fallback آمن، واسم ووصف وحالة ومؤشر اعتماد، وتفاصيل تفتح Sheet حقيقيًا. تعرض الأفعال حسب حالة المتجر: اعتماد أو رفض للـ`pending`، تعليق للـ`active`، إعادة تفعيل للحالات `rejected`/`suspended`/`paused`، وحذف مع تأكيد صريح. بعد المراجعة أو الحذف يعاد تحديث المتاجر والمنتجات والموجز، وتظهر رسائل نجاح أو خطأ من المصدر.

في الخادم، يترجم `moderateStore` الفعل إلى صلاحية مناسبة، ثم يستدعي RPC `admin_moderate_store` مع هوية المراجع ويسجل `store.<action>` في سجل التدقيق، بما في ذلك إشعار/طلب/معرّف التاجر عندما يعيده المصدر. لم تُضف واجهة توثيق Pro إلى قائمة المتاجر؛ التوثيق مستقل في مساره، ولا تعني حالة فتح المتجر شارة تحقق.
