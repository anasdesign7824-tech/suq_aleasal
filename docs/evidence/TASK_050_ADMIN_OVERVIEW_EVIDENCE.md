# دليل TASK 050 — نظرة عامة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** تدقيق صفحة النظرة العامة في لوحة الإدارة المحلية، مع منع عرض حالة إنتاج مضللة عند فشل مصدر الموجز، ودون تعديل DB/API/RLS/الصلاحيات.

## ملاحظة المصدر

فهرس ما قبل التغيير يحدد `Home.tsx` و`admin-api.ts` لنطاق TASK 050 ويصف مرجعًا مكتبيًا بأبعاد 1600×1000. ملفا `screens/050_admin_overview.png` و`explanations/050_admin_overview.md` غير موجودين في checkout الحالي ولم يظهر مسارهما في شجرة GitHub المتاحة؛ لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يحمّل `Home` الموجز عبر `adminApi.overview` من خلال helper موحد يعيد حالة `loading` أو `data` أو `error`. كانت الصفحة تعرض شارة «مصدر Supabase الحي» وبطاقات المقاييس حتى عند فشل الموجز، مع بقاء زر تصدير الموجز بلا أثر مفيد عندما لا توجد بيانات. عولج ذلك داخل `Home.tsx` فقط: عند `overview.error` تظهر `ErrorState` برسالة المصدر وزر «إعادة المحاولة» الحقيقي، ولا تعرض الصفحة شارة نجاح أو مقاييس غير موثقة؛ كما عُطّل «تصدير الموجز» أثناء التحميل أو في غياب البيانات أو عند الخطأ. بقي التصدير الحقيقي عبر `downloadSnapshot` عند وجود بيانات، وبقيت مصادر الطلبات والمنتجات ومساراتها كما هي.

التعديل محدود بواجهة الحالة ولا يضيف endpoint أو عقدًا أو بيانات تجريبية. لم تُستبدل حالة المصدر الحي بنجاح تقديري، ولم تُعتبر تحذيرات حجم bundle عطلًا وظيفيًا.

## بوابات الإثبات

| البوابة | النتيجة |
|---|---|
| `pnpm test` | PASS — 8 ملفات اختبار قائمة |
| `pnpm check` | PASS — `tsc --noEmit` |
| `pnpm build` | PASS — Vite وesbuild؛ تحذير chunk أكبر من 500 kB بقي تحذير أداء |
| مراجعة المصدر | PASS — error state يستدعي refresh، وexport محمي بـloading/data/error guards |

النتيجة المهيكلة محفوظة في `artifacts/task050_admin_overview_result.json`.

## الحدود والقرار

لم تُشغّل مقارنة golden لأن Markdown وPNG المصدرين غير موجودين. ولا يُدّعى screenshot browser أو runtime مرئي من بيئة المتصفح المعزولة. تبقى بيانات الموجز مصدرية، ولا يظهر نجاح أخضر عند فشل المصدر.

**قرار TASK 050:** PASS للتعديل الوظيفي والبناء والاختبارات، مع GAP-024 لفقدان أصول التدقيق البصرية/السلوكية. لا تغيير DB/API/RLS/الصلاحيات.
