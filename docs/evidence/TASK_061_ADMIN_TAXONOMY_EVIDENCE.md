# دليل TASK 061 — التصنيفات والأنواع في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** مراجعة مرجع التصنيفات الهرمية وأنواع العسل في Admin، مع تحصين حفظ النماذج دون تغيير عقد البيانات أو قاعدة البيانات.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 061 بـ`AdminOperations.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/061_admin_taxonomy.png` و`explanations/061_admin_taxonomy.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يعرض `TaxonomyPanel` نوع العسل المرجعي والتصنيفات الهرمية من المصدر، مع حالات loading/error/retry وempty، وأزرار تعديل ونماذج upsert. يرسل الحفظ عبر `adminApi.upsertTaxonomy` و`adminApi.upsertCategory`، وتبقى التحققات والصلاحية وسجل التدقيق في الخادم القائم.

كُشف أن نموذجي الحفظ لا يملكان حارسًا مستقلًا، ما يسمح بإرسال مزدوج عند النقر السريع أو أثناء القراءة التالية. أضيفت حالتا `savingTaxonomy` و`savingCategory`، وتعطيل زر كل نموذج أثناء طلبه، مع بقاء النجاح يعيد القراءة والخطأ يظهر للمستخدم. لم تُضف تصنيفات أو بيانات افتراضية ولم يتغير API أو DB/RLS/permissions.

## الحدود والقرار

لم تُجرَ كتابة تصنيف Production حي خلال المهمة، ولم تُشغّل مقارنة golden لغياب Markdown وPNG. لا يُدّعى تعديل بيانات العميل أو مزامنة حية؛ إثبات ذلك يحتاج عملية كتابة واعتمادًا آمنًا.

**قرار TASK 061:** PASS للتعديل الوظيفي المحدود والبناء والاختبارات، مع GAP-035 لفقدان أصول التدقيق البصرية/السلوكية. لا تغيير DB/API/RLS/الصلاحيات.
