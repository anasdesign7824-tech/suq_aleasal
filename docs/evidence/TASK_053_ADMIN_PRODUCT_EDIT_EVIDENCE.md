# دليل TASK 053 — تعديل منتج في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** تدقيق محرر تعديل المنتج من واجهة Admin إلى `updateProduct`، مع تثبيت أن التعديل يشمل الحقول والصور وسجل التدقيق ضمن العقود القائمة.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 053 بـ`ProductEditPanel.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/053_admin_product_edit.png` و`explanations/053_admin_product_edit.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد المصدرّي

يقرأ `ProductEditPanel` الحقول الحالية للمنتج ويتيح تعديل الاسم العربي والإنجليزي والوصف والتصنيف والنوع ودرجة الجودة والسعر والعملة والحالة و`metadata` والصور. يتحقق النموذج من الاسم، ويحاول تحليل metadata ككائن JSON غير مصفوفة، ويرفض السعر غير الرقمي أو السالب، ويعطل الحفظ أثناء الحفظ أو الرفع. قراءة التصنيف لها حالة خطأ عربية وزر retry من TASK 051، ولا يمنع ذلك تعديل الحقول الأخرى عند غياب مصدر التصنيف إلا اختيار التصنيف نفسه.

عند حفظ الصور المعدلة تُرسل `imageUrls` صراحة، فيحذف الخادم صور المنتج القديمة ثم يعيد إدخال القائمة المرتبة، أما بقية الحقول فتُحوّل إلى patch منضبط. يتحقق الخادم من `product.write`، ويكتب الحقول، ويسجل `product.update` مع قائمة الحقول المتغيرة. `onSaved` يعيد إغلاق اللوحة وتحديث القائمة والموجز، و`onClose` يغلقها دون حفظ؛ لا يوجد نجاح وهمي أو API جديد.
