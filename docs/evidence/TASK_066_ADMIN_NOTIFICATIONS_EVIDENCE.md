# دليل TASK 066 — الإشعارات الإدارية

**التاريخ:** 24 أغسطس 2026

**النطاق:** مراجعة قائمة الإشعارات والإرسال لمستخدم أو للجميع ورفع الصورة الاختيارية، مع إبقاء مسارات الإشعار المصدرية دون تغيير.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 066 بـ`AdminPeople.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/066_admin_notifications.png` و`explanations/066_admin_notifications.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

تعرض `NotificationsPanel` الإشعارات الموجودة وتتيح اختيار مستخدم من الحسابات الحالية أو الإرسال العام، وتتحقق من العنوان والمستخدم وترسل عبر `adminApi.sendNotification`. رفع الصورة يمر عبر `adminApi.uploadPublicImage` ويستخدم معاينة محلية للمصدر المرفوع.

كُشف أن فشل قراءة القائمة يظهر كـtoast فقط، وأن حقل الملف يقبل أي MIME قبل الرفع. أضيفت حالة `error` مع retry واضح وزر تحديث وصولي، والتحقق الصريح من PNG/JPEG/WebP قبل قراءة bytes، مع بقاء حارس الإرسال وحارس الحجم ومسارات الإشعار والرفع كما هي. لم تُرسل إشعارات فعلية ولم تُستخدم بيانات تجريبية.

## بوابات الإثبات

## الحدود والقرار

لم تُنفذ عملية إرسال أو رفع Production حية، ولم تُشغّل مقارنة golden لغياب Markdown وPNG. لا يُدّعى وصول push أو مزامنة جهازية؛ المسار المثبت هو إنشاء سجل الإشعار عبر العقد القائمة.

**قرار TASK 066:** PASS للتعديل الوظيفي المحدود والبناء والاختبارات، مع GAP-040 لفقدان أصول التدقيق البصرية/السلوكية. لا تغيير DB/API/RLS/الصلاحيات.
