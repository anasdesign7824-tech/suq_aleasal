# UX-15 — أفعال الصور المباشرة في الملف الشخصي

## التنفيذ

أضيفت أفعال كاميرا مباشرة داخل رأس الملف الشخصي الموحد. يظهر زر تغيير الغلاف داخل مساحة الغلاف، ويظهر زر تغيير الصورة الشخصية داخل مساحة الصورة نفسها. الزران يعطلان أثناء الرفع، ولكل منهما tooltip عربي واضح. بقي زر تعديل النصوص الكامل كما هو.

عند اختيار صورة، يعاد استخدام مسار التخزين الموجود في `uploadMerchantImage`، ثم يحدث `updateUserProfile` حقل الصورة المختار فقط؛ لذلك لا يمس تغيير الغلاف الصورة الشخصية ولا يمس تغيير الصورة الشخصية الغلاف. بعد نجاح الحفظ يحدث العرض محليًا فورًا، وتظهر رسالة نجاح، بينما فشل الرفع أو التحديث يعرض رسالة الخطأ ولا يدعي نجاحًا.

## التحقق

- `flutter analyze`: `No issues found!` قبل اختبار hit-test.
- `flutter test test/profile_header_image_actions_test.dart`: **نجاح**.
- اكتشف الاختبار أن زر الصورة الشخصية كان خارج hit-test بسبب تداخل avatar مع `SizedBox` بارتفاع 150؛ أُعيد ضبط مساحة الرأس إلى 190 مع بقاء الغلاف 150، فأصبح الزر داخل مساحة التفاعل، ثم نجح الاختبار.

## حدود الإثبات

لم يُنفذ اختيار ملف حقيقي أو رفع Storage على جهاز Android في هذه الجولة؛ ذلك يحتاج جهازًا/محاكيًا. تم إثبات وجود الأزرار ونقرها، وربط كود الرفع والتحديث بمسار repository القائم.
