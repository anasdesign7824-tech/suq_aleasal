**النطاق:** مراجعة لوحة الخطط والحملة وتسعير الخصم والدفع المحلي وطلبات التفعيل، مع منع إظهار حالات فارغة مضللة عند فشل المصدر.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 059 بـ`AdminPlansPanel.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/059_admin_plans_campaign.png` و`explanations/059_admin_plans_campaign.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

تقرأ اللوحة الخطط والحملة والمدفوعات والاشتراكات وطلبات التصميم وإعدادات الحوالة والمستخدمين من مسارات Admin القائمة. تعرض بطاقات الأسعار السعر الأساسي والخصم الذي يعاد حسابه من بيانات الحملة، وتعرض الحملة قابلة للتفعيل/الإيقاف، والحوالة المحلية كخيار متاح، مع بقاء البطاقة مجمدة خادميًا، وطلبات الحوالة وفتح السند والتأكيد/الرفض/الرد، والتفعيل اليدوي للمستخدم والباقة.

كانت `refresh` تستخدم `Promise.all` وتعرض toast فقط عند فشل أي مصدر، ثم تترك اللوحة في حالات فارغة يمكن فهمها خطأ على أنها لا تحتوي بيانات. عولج ذلك بإضافة `error` مستمر، وتصفير الخطأ عند بدء القراءة، وعرض تنبيه `role=alert` وزر «إعادة المحاولة» مع تعطيل التكرار أثناء التحميل. لم يتغير أي endpoint أو عقد تسعير أو تفعيل أو دفع، ولم تُضف بيانات Demo.
