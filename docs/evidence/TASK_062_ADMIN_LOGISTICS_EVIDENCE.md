# دليل TASK 062 — التوصيل ونقاط الاستلام في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** مراجعة مراجع طرق التوصيل والمناطق وإعدادات المتجر ونقاط الاستلام، مع حماية القراءة والحفظ والحذف دون تغيير عقود DB/API/RLS.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 062 بـ`AdminOperations.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/062_admin_logistics.png` و`explanations/062_admin_logistics.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يقرأ `LogisticsPanel` طرق التوصيل والمناطق ثم يقرأ إعدادات المتجر المختار. يعرض محررات خيارات التوصيل ونقاط الاستلام مع اختيار المحافظة ثم المديرية، والرسوم والعملة والمدة والعنوان والهاتف. الحفظ يمر عبر `upsertDeliveryOption` و`upsertPickupLocation`، والحذف عبر المسارات القائمة مع تأكيد، وتبقى الجداول المشتركة التي يستهلكها العميل كما هي.

كُشف أن فشل قراءة المراجع أو إعدادات المتجر كان يظهر كـtoast ثم قد يترك واجهة فارغة، كما أن أفعال الحذف لا تملك حارسًا لكل سجل. أضيفت حالتا `error/storeError` مع retry، وحالة `removingId` لتعطيل حذف السجل أثناء الطلب. بقيت حماية الحفظ القائمة والتصفية الهرمية وقواعد الصلاحيات دون تغيير، ولم تُضف بيانات تجريبية.
