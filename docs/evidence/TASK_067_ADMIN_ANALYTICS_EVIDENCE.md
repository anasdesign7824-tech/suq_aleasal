# دليل TASK 067 — الإحصاءات التشغيلية في لوحة الإدارة

**التاريخ:** 24 أغسطس 2026

**النطاق:** مراجعة مؤشرات التشغيل المشتقة من Production ومنع عرض قراءة فارغة أو غير صالحة على أنها بيانات مكتملة.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 067 بـ`AdminPeople.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/067_admin_analytics.png` و`explanations/067_admin_analytics.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

يقرأ `AnalyticsPanel` من `adminApi.analytics` ويعرض مؤشرات المتاجر النشطة والمنتجات المنشورة والطلبات المفتوحة والإشعارات غير المقروءة مع زمن القراءة. النص يوضح أن الأرقام من الجداول المصدرية وليست تقديرية.

كُشف أن الرد الفارغ أو `null` بعد انتهاء loading كان يؤدي إلى إطار مؤشرات فارغ وعبارة زمن قراءة غير معرّف، كما أن زر التحديث يبقى قابلًا للنقر أثناء الطلب، وفشل القراءة لا يملك retry مضمّنًا. أضيف تعطيل التحديث أثناء loading، ورسالة خطأ مع إعادة محاولة، وحالة صريحة للرد غير الصالح، مع بقاء الحسابات والعقد المصدرية كما هي.

## بوابات الإثبات

| البوابة | النتيجة |

## الحدود والقرار

لم تُجرَ قراءة Analytics Production حية من جلسة اعتماد، ولم تُشغّل مقارنة golden لغياب Markdown وPNG. لا يُدّعى أن هذه الشاشة تقيس مشاهدات أو تحويلات غير موجودة في العقد الحالي.

**قرار TASK 067:** PASS للتعديل الوظيفي المحدود والبناء والاختبارات، مع GAP-041 لفقدان أصول التدقيق البصرية/السلوكية. لا تغيير DB/API/RLS/الصلاحيات.
