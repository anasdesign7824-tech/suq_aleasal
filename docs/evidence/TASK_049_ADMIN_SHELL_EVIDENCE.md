# دليل TASK 049 — هيكل لوحة الإدارة والتنقل

**التاريخ:** 23 أغسطس 2026

**النطاق:** تدقيق الغلاف الإداري والقائمة الجانبية على سطح مكتب محلي، مع الحفاظ على فصل Admin عن تطبيق العميل والتاجر.

## ملاحظة المصدر

فهرس ما قبل التغيير يحدد `Home.tsx` و`App.tsx` و`index.css` و`admin-api.ts` لنطاق TASK 049، ويصف المرجع المكتبي بأبعاد 1600×1000. ملفا `screens/049_admin_shell.png` و`explanations/049_admin_shell.md` غير موجودين في checkout الحالي ولم يظهر مسارهما في شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل بالتخمين. سُجلت هذه الحالة في GAP-023، مع إبقاء المراجعة محصورة في المصدر الفعلي.

## الجرد المصدرّي

يضع `App.tsx` بوابة `AdminAuthGate` قبل `Home`. داخل `Home.tsx` عرّفت القائمة `navItems` خمسة عشر مسارًا فعليًا موزعة على مجموعات «التشغيل»، «دورة التاجر»، «المحتوى والمرجع»، «الحوكمة»، و«الحسابات والتحليل». يصدّر المصدر `ADMIN_NAVIGATION_ITEM_COUNT`، ويضع `data-testid="admin-navigation"` و`data-nav-item-count` على عنصر التنقل؛ كل عنصر يستدعي `setActiveView` ثم يغلق sheet الهاتف، ولا يعتمد على route شكلي أو زر بلا انتقال.

يستخدم سطح المكتب aside ثابتًا على اليمين بعرض 72rem تقريبًا، مع `overflow-y-auto` و`overscroll-contain` للقائمة حتى لا تُقص العناصر عند كثرتها. وعلى الشاشات الأصغر يستخدم `SheetContent side="right"` بنفس navigation component، مع عنوان accessible مخفي وزر إغلاق حقيقي. يعرض الرأس عنوان المسار الحالي، زر الإشعارات، زر الخروج، وحالة المصدر، بينما يربط كل ViewKey بمكوّن المحتوى الحالي؛ لم تُضف API أو DB أو RLS أو صلاحيات.
