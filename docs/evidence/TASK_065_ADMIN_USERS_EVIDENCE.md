# دليل TASK 065 — المستخدمون في لوحة الإدارة

**التاريخ:** 24 أغسطس 2026

**النطاق:** مراجعة دليل الحسابات والبحث والترقيم والحذف وعرض بيانات الملف والمتجر، مع إبقاء حدود مخطط Production كما هي.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 065 بـ`AdminPeople.tsx` و`admin-api.ts` و`admin-data.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/065_admin_users.png` و`explanations/065_admin_users.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

تعرض `UsersPanel` بيانات المستخدم من `users` و`profiles` وSupabase Auth وطلبات التجار والمتجر، مع صورة آمنة، حالة الدور، أزمنة الهوية والدخول والنشاط، الهاتف والموقع والمتجر وحدود الشبكة. القراءة تمر عبر `adminApi.users` ببحث وترقيم، والحذف يمر عبر `adminApi.deleteUser` مع تأكيد وحارس لكل مستخدم، دون تغيير قواعد الحذف أو التفويض.

كُشف أن البحث والتحديث يمكن أن يبدآ أثناء طلب قائم، وأن فشل القراءة يظهر دون مسار retry داخل الحالة. عُطلت أزرار البحث والتحديث أثناء loading، وأضيف زر إعادة المحاولة في حالة الخطأ. بقيت pagination وحماية الحذف وfallback للصورة وعبارة عدم توفر IP غير المسجل كما هي، ولم تُخترع بيانات شبكة أو موقع.
