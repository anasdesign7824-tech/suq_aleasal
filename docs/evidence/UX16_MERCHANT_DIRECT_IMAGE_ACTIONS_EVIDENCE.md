# UX-16 — أفعال الصور المباشرة في مساحة التاجر

أضيفت إلى رأس المتجر الموحد أفعال كاميرا مباشرة لتغيير صورة الغلاف وشعار المتجر. يظهر زر الغلاف بجوار زر التحديث عند وجوده، ويظهر زر الشعار داخل مساحة الشعار، مع تعطيل الأفعال أثناء الرفع. بقي محرر المتجر الكامل متاحًا للبيانات والقنوات والمعرض.

المسار التنفيذي يقرأ جلسة التاجر، يرفض الجلسة غير الصالحة برسالة واضحة، يختار الصورة، يرفعها عبر `uploadMerchantImage`، ثم يرسل `updateMerchantWorkspace` مع اسم المتجر والبيانات الحالية وتغيير URL للصورة المطلوبة فقط. عند الفشل لا يعرض نجاحًا، وعند النجاح يعيد تحميل workspace ويعرض رسالة نجاح.

التحقق المنفذ هو `flutter analyze` بنتيجة `No issues found!`، ثم `flutter test test/profile_header_image_actions_test.dart test/store_header_image_actions_test.dart` مع نجاح الاختبارين. تم إثبات وجود ونقر الأفعال في الرأس؛ أما اختيار ملف حقيقي وStorage على Android ومزامنة جهازين فتبقى ضمن اختبار القبول اليدوي الذي يحتاج جهازًا أو محاكيًا.
