# دليل TASK 055 — تفاصيل المتجر في لوحة الإدارة

**التاريخ:** 23 أغسطس 2026

**النطاق:** مراجعة Sheet تفاصيل المتجر داخل Admin، وتوحيد معالجة صور الغلاف والشعار وإظهار معرّفات المصدر دون إضافة عقد جديد.

## ملاحظة المصدر

فهرس ما قبل التغيير يربط TASK 055 بـ`Home.tsx` و`admin-api.ts` ويصف مرجعًا مكتبيًا 1600×1000. ملفا `screens/055_admin_store_detail.png` و`explanations/055_admin_store_detail.md` غير موجودين في checkout الحالي أو شجرة GitHub المتاحة، لذلك لم تُنشأ صورة أو golden بديل.

## الجرد والتنفيذ

كانت تفاصيل المتجر تفتح Sheet حقيقيًا من `StoresPanel`، لكنها تعرض الغلاف عبر `img` مباشر وتُظهر حقولًا محدودة، ما قد ينتج صورة مكسورة عند رابط غير صالح ولا يوضح هوية المصدر. عولج ذلك داخل `Home.tsx` فقط باستيراد `AdminSafeImage` واستخدامه للغلاف والشعار مع fallback عربي/مرئي، وإظهار الحالة والاعتماد ومعرّف المتجر ومعرّف التاجر ومعرّف المنطقة. بقي الهاتف موصوفًا بصدق بأنه غير موجود في عقد قائمة المتاجر الحالي بدل اختراع قيمة أو endpoint.

لم يتغير فتح/إغلاق Sheet أو callbacks الاعتماد والحذف، ولم تُضف بيانات أو صلاحيات. الصورة الآمنة لا تتجاوز العقد؛ هي تعالج حالة رابط الصورة الفاشل محليًا وتترك المصدر كما هو.
