# TASK 068 — دليل حالة التحميل المشتركة

## نطاق المهمة

تطلب TASK 068 توحيد حالة تحميل البيانات لكل أدوار تطبيق عسلكم، مع سلوك قابل لإعادة الإنتاج لا يعتمد على بيانات أو نجاح وهمي. فُحصت المسارات المشتركة والمستهلكة قبل أي تعديل.

## نتيجة جرد المصدر

المراجع المتوقعة `screens/068_state_loading.png` و`explanations/068_state_loading.md` غير موجودة في checkout الحالي، كما يثبت خط الأساس `artifacts/task060_080_gap_baseline.json` عدم وجود أصول 068–080. لم تُنشأ صورة أو عقد بديل، ولم يُستخدم actual كـ baseline.

## ما هو موجود فعليًا

يحتوي `apps/mobile_flutter/lib/core/assal_widgets.dart` على المكونات المشتركة التالية:

| المكوّن | السلوك المثبت |
|---|---|
| `AssalGlassLoading` | مؤشر عسلكم متحرك، نص عربي قابل للتخصيص، و`Semantics(liveRegion: true)`؛ القيمة الافتراضية `جارٍ تجهيز تجربة عسلكم...`. |
| `AssalFutureStateView` | يحول Future المعلق إلى حالة التحميل المشتركة، والخطأ إلى `AssalMessageCard` مع retry، والنتيجة إلى builder. |
| `AssalStateView` | يطبع `AssalLoading` و`AssalData` و`AssalEmpty` و`AssalError` إلى واجهة حالات واحدة، مع أيقونة خطأ مناسبة وإعادة محاولة عند قابلية ذلك. |
| `AssalMessageCard` | رسالة عربية مركزية مع أيقونة وإجراء retry اختياري حقيقي. |

تمت مراجعة المستهلكين الأساسيين: `customer_discovery.dart` يستخدم الحالة المشتركة في بوابة الصفحة وأقسام البنرات والتصنيفات والمنتجات والمتاجر؛ `customer_account.dart` يستخدمها في المصادقة والملف؛ `customer_catalog.dart` يستخدمها في تفاصيل المنتج والمنتجات المشابهة وملف المتجر؛ و`merchant_dashboard.dart` يستخدمها في بوابة الجلسة والكتالوج والطلبات والتعليقات والإحصاءات. تبقى مؤشرات الإرسال الصغيرة داخل أزرار الفعل في `customer_request_detail.dart` و`customer_social.dart` نطاقًا منفصلًا لحالات الإجراء، وليست حالة تحميل صفحة TASK 068.

## التغيير المبرر

لم يثبت الجرد فجوة سلوكية في المكوّن المشترك نفسه: حالة Future المعلق تستخدم مؤشرًا موحدًا وموسومًا بالعربية، وحالات الخطأ/الفراغ تمر عبر primitives مشتركة. لذلك لم يُجر تغيير إنتاجي تجميلي أو إعادة بناء غير مبررة. أُضيف فقط اختبار regression مستقل يثبت أن المكوّن الظاهر والقابل للوصول يبقى أثناء Future المعلق ثم ينتقل إلى النتيجة بعد إكمال المصدر.
