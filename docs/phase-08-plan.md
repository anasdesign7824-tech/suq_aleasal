# Phase 8 — صفحة الهبوط التجريبية

## الهدف

إنشاء صفحة هبوط عربية RTL مستقلة باسم عسلكم، توضّح قيمة المنصة للعملاء والتجار، وتعرض هوية العلامة والمنتجات والمناطق من Demo Catalog، دون بيع مباشر أو دفع أو ادعاءات اجتماعية مصطنعة.

## نطاق Demo

تكون الصفحة تعريفية وتعرض مصدر البيانات التجريبي بوضوح. أزرار التواصل والانضمام تستعرض تدفقًا توضيحيًا داخل الواجهة ولا تجمع بيانات شخصية أو تشغّل عملية إنتاجية.

لا تستخدم الصفحة تقييمات أو شهادات أو مراجعات عملاء مصطنعة بأي شكل. تركز الأدلة الاجتماعية، إن لزم عرضها مستقبلًا، على بيانات موثقة فقط بعد تفعيل مصدر الإنتاج.

## الهوية

تعتمد على الشعار المرجعي والخط المرفق ولوحة العسل الذهبية والبني اليمني والعاجي. تستخدم الصور المولدة كصور سردية مخصصة، ولا تستبدل الشعار المرجعي أو تدعي أنها صور منتجات حقيقية.

الاسم الهندسي الداخلي هو `Souq Al Assal / سوق العسل`، والاسم التجاري الظاهر هو **عسلكم**. تبقى تقنية صفحة الهبوط React/TypeScript static، وتقرأ Demo Catalog فقط إلى حين مرحلة مصدر الإنتاج المعتمدة.

## بوابة القبول

PLAN ثم IMPLEMENT ثم `pnpm check` و`pnpm build` وفحص لسطح المكتب والهاتف ومراجعة أسلوب مستقلة، ثم Evidence وcommit قبل الانتقال إلى الاختبارات النهائية.

تُراجع مسارات الأصول والخطوط والشعار، ويثبت عدم وجود Supabase أو مفاتيح أو مصدر إنتاج في Demo landing قبل إغلاق المرحلة.
