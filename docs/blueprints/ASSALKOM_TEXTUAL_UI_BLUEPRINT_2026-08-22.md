# مخطط عسلكم النصي الشامل لتصميم UX

## الغرض من الملف

هذا الملف هو **رسم تخيلي نصي فقط** لتطبيق عسلكم ولوحة الإدارة. لا يحتوي على كود، ولا يفرض ألوانًا أو أحجامًا أو أسلوبًا بصريًا نهائيًا. كل سطر يصف مساحة أو عنصرًا أو زرًا أو حالة أو مسارًا يمكن تحويله لاحقًا إلى تصميم يدوي وصور واجهات.

> **قاعدة الرسم:** اكتب اسم الصفحة، ثم رتّب عناصرها من أعلى الشاشة إلى أسفلها. بعد ذلك اكتب الحالات البديلة، ثم اكتب وظيفة كل زر وانتقاله. التصميم النهائي يغيّر الشكل، لكن لا يغيّر معنى العناصر أو صلاحيات الأدوار.

---

# 1. قاموس العناصر النصية

| الرمز النصي | نوع العنصر | ما الذي يرسمه المستخدم؟ |
|---|---|---|
| `[شريط أعلى]` | رأس الصفحة | عنوان الصفحة، زر الرجوع، البحث، الإشعارات، أو الإجراء الرئيسي. |
| `[غلاف]` | صورة عريضة | صورة الغلاف للملف أو المتجر. |
| `[أفاتار]` | صورة دائرية أو مربعة | صورة الشخص أو شعار المتجر. |
| `[حقل]` | إدخال نص | اسم الحقل، القيمة الحالية، النص المساعد، وحالة الخطأ. |
| `[قائمة اختيار]` | اختيار مرجعي | قائمة اقتراحات، مع السماح بكتابة قيمة خاصة عند الحاجة. |
| `[بطاقة]` | وحدة محتوى | صورة، عنوان، معلومات مختصرة، أزرار، وحالة. |
| `[زر رئيسي]` | إجراء أساسي | الإجراء الأهم في الصفحة، مثل حفظ أو إرسال أو طلب. |
| `[زر ثانوي]` | إجراء مساعد | فتح التفاصيل، مشاركة، تحديث، تعديل، أو إلغاء. |
| `[حالة تحميل]` | انتظار | مساحة مؤقتة توضّح أن المصدر يُقرأ. |
| `[حالة فارغة]` | لا توجد بيانات | أيقونة، عنوان، شرح، وزر تحديث أو إجراء مناسب. |
| `[حالة خطأ]` | فشل | سبب واضح، رسالة عربية، وزر إعادة المحاولة عند إمكانية ذلك. |
| `[شريط تبويب]` | تقسيم الصفحة | تبويبات الصفحة، مع إبراز التبويب الحالي. |
| `[شريحة]` | صورة أو محتوى متحرك | بنر أو صورة معرض مع مؤشر التقدم. |
| `[وسم]` | معلومة صغيرة | نوع المنتج، الجودة، المنطقة، الحالة، أو الميزة. |
| `[عداد]` | رقم مرتبط ببيانات | المتابعون، الإعجابات، المراجعات، الطلبات، أو الإشعارات. |
| `[نافذة]` | Dialog أو Bottom Sheet | اختيار، تأكيد، إدخال، أو عرض تفاصيل دون مغادرة الصفحة. |

# 2. قواعد الهوية الموحدة بين الأدوار

التطبيق يعرض **الكيان نفسه بالشكل والمعلومات نفسيهما** للعميل والتاجر والإدارة. الفرق يكون في الأزرار، وإمكانية التحرير، وإجراءات الإدارة، وليس في إعادة رسم المنتج أو المتجر بثلاثة تصاميم متناقضة.

| الكيان | ما يراه العميل | ما يراه التاجر | ما تراه الإدارة |
|---|---|---|---|
| الملف الشخصي | بيانات عامة وتفاعل محدود | بياناته مع أزرار التحرير والرفع | بيانات الحساب وحالة الإدارة وسجل العمليات المسموح به |
| المتجر | الغلاف، الشعار، المنتجات، المعلومات، التواصل، المتابعون | نفس الهوية مع تعديل الصور والبيانات والمنتجات | نفس الهوية مع المراجعة والاعتماد والتعليق والحذف |
| المنتج | الصور والمواصفات والسعر والتوفر والتقييم والتعليقات | نفس المنتج مع إضافة وتعديل وإدارة الصور والحالة | نفس المنتج مع المراجعة والتعديل والحذف والنشر |
| الطلب | إنشاء طلب ومتابعة الرد | استقبال الطلب وتفاصيله والرد | مراقبة الطلب ومسار التدقيق عند الحاجة |
| التعليق والتقييم | القراءة والكتابة وفق الحالة | قراءة تعليقات منتجاته وإشعاراتها | المراجعة أو الإدارة حسب الصلاحية |

# 3. أنواع التطبيق والأدوار

## 3.1 الزائر غير المسجل

الزائر يستطيع فتح الصفحة الرئيسية، قراءة البنرات والتصنيفات والمنتجات والمتاجر والمواصفات العامة، والبحث والتصفية. عند تنفيذ إجراء يحتاج حسابًا تظهر نافذة دخول واضحة بدل فشل صامت.

```text
[تطبيق عسلكم]
  [شعار عسلكم]
  [زر البحث]
  [زر تسجيل الدخول]

[محتوى الاستكشاف]
  [البنرات]
  [التصنيفات]
  [منتجات مختارة]
  [الأعلى مشاهدة]
  [وصل حديثًا]
  [الأعلى تقييمًا]
  [المتاجر]

[الإجراء المحمي]
  عند الضغط على إعجاب / حفظ / متابعة / تعليق / تقييم / طلب:
  [نافذة تسجيل الدخول]
  النص: «سجّل الدخول لإتمام هذا الإجراء»
  [زر تسجيل الدخول]
  [زر إلغاء]
```

## 3.2 العميل المسجل

العميل المسجل هو المستخدم الذي يتصفح ويتفاعل ويطلب التواصل. تظهر له بياناته، ومحفوظاته، ومتابعاته، وطلباته، ورسائله، وإشعاراته.

```text
[التطبيق]
  [الرئيسية] [البحث] [المحفوظات] [المتابعات] [الملف الشخصي]
  [الإشعارات] داخل الرأس أو كعداد
```

## 3.3 التاجر

التاجر هو مستخدم لديه مساحة متجر. يفتح المتجر ويحرر بياناته ويرفع المنتجات، لكن حالة النشر أو التفعيل تظل خاضعة لدورة الإدارة. لا تُعرض في مساره القياسي عبارات Pro أو شارات التوثيق المؤجلة.

```text
[مساحة التاجر]
  [نظرة عامة]
  [الكتالوج]
  [الطلبات]
  [إدارة]
    [المسودات والمراجعة]
    [الإحصاءات]
    [التعليقات]
  [تعديل المتجر]
  [إضافة منتج]
```

## 3.4 الإدارة المحلية

الإدارة لوحة مستقلة محلية ذات صلاحيات، تقرأ من Production عبر الخادم المصرح. هي ليست نسخة من شاشة العميل، لكنها تستخدم نفس لغة الكيانات والبيانات.

```text
[دخول الإدارة]
  [البريد الإداري]
  [كلمة المرور]
  [زر دخول]
  [رسالة الخطأ]
  [حالة الجلسة]

[لوحة الإدارة]
  [شريط علوي]
  [قائمة جانبية]
  [محتوى الصفحة الحالية]
  [نوافذ التفاصيل والتأكيد]
```

# 4. الغلاف العام لتطبيق العميل

## 4.1 شريط التنقل السفلي

```text
[شريط تنقل سفلي]
  [الرئيسية]
  [البحث]
  [المحفوظات]
  [المتابعات]
  [الملف الشخصي]
```

كل عنصر يظهر بأيقونة وعنوان عربي وحالة محددة للعنصر النشط. لا يوجد عنصر شكلي بلا انتقال.

## 4.2 رأس الصفحات

| العنصر | النص أو المحتوى | الإجراء |
|---|---|---|
| زر الرجوع | سهم رجوع | العودة للصفحة السابقة. |
| عنوان الصفحة | اسم الصفحة بالعربية | ثابت وواضح. |
| زر البحث | أيقونة بحث | فتح شاشة البحث أو التركيز على حقل البحث. |
| زر الإشعارات | جرس مع عداد | فتح الإشعارات. |
| زر المشاركة | «مشاركة» | نسخ أو مشاركة بطاقة المنتج أو المتجر. |
| زر التحديث | «تحديث» | إعادة قراءة المصدر الحقيقي. |

## 4.3 حالات عامة

```text
[حالة التحميل]
  [أيقونة تحميل أو مساحة هيكلية]
  النص: «جارٍ تحميل البيانات...»

[حالة فارغة]
  [أيقونة مناسبة]
  [عنوان الحالة]
  [شرح مختصر]
  [زر تحديث أو الإجراء المناسب]

[حالة خطأ]
  [أيقونة اتصال أو خادم]
  [عنوان: «تعذر تحميل البيانات الآن»]
  [شرح السبب بالعربية]
  [زر إعادة المحاولة]

[حالة عدم الاتصال]
  [أيقونة اتصال منقطع]
  [النص: «تحقق من الاتصال ثم أعد المحاولة»]
```

# 6. شاشة الدخول والتحقق بالبريد

## 6.1 شاشة تسجيل الدخول الأساسية

```text
[شعار عسلكم]
[العنوان: «مرحبًا بك في عسلكم»]
[شرح: «أدخل بريدك الإلكتروني للمتابعة»]

[حقل البريد الإلكتروني]
  الاسم: «البريد الإلكتروني»
  النص المساعد: «name@example.com»
  [رسالة خطأ البريد إن وجدت]

[زر رئيسي: «إرسال رمز التحقق»]
[زر ثانوي: «إنشاء حساب» أو نفس المسار الموحد]
[رابط المساعدة أو الدعم]
```

## 6.2 نافذة رمز التحقق OTP

```text
[نافذة: «تحقق من بريدك»]
[النص: «أرسلنا رمز التحقق إلى البريد المدخل»]
[خانات الرمز]
[عداد إعادة الإرسال]
[زر: «إعادة إرسال الرمز»]
[زر: «تحقق»]
[زر: «تعديل البريد»]
[رسالة رمز غير صحيح]
[رسالة انتهاء الرمز]
[حالة تحميل أثناء التحقق]
```

## 6.3 تأكيد كلمة المرور عند إنشاء حساب جديد

```text
[العنوان: «أنشئ كلمة مرورك»]
[شرح: «ستستخدمها لتأمين حسابك»]
[حقل كلمة المرور]
[حقل تأكيد كلمة المرور]
[مؤشر القوة]
  [ضعيفة]
  [متوسطة]
  [قوية]
[قواعد كلمة المرور]
[زر: «حفظ ومتابعة»]
[رسالة عدم التطابق]
```

## 6.4 الدخول بحساب موجود

```text
[البريد الإلكتروني]
[زر: «إرسال رمز التحقق»]
[نافذة OTP]
[بعد النجاح: الانتقال إلى الصفحة السابقة أو الرئيسية]
```

# 7. الصفحة الرئيسية والاستكشاف

## 7.1 هيكل الصفحة الرئيسية

```text
[شريط علوي مثبت]
  [شعار عسلكم]
  [حقل بحث مختصر: «ابحث عن عسل أو متجر»]
  [زر الإشعارات + عداد]

[منطقة البنر]
  [شريحة بنر]
  [النص الرئيسي للبنر]
  [النص الثانوي]
  [زر الإجراء إن وجد]
  [مؤشرات الشرائح]
  [حالة فراغ البنرات]

[قسم: «استكشف حسب التصنيف»]
  [زر: «كل التصنيفات»]
  [بطاقات التصنيفات الأفقية]
    [أيقونة التصنيف]
    [اسم التصنيف]
    [عدد أو وصف مختصر]

[قسم: «منتجات مختارة»]
  [زر: «عرض الكل»]
  [شبكة بطاقات المنتجات]

[قسم: «الأكثر مشاهدة»]
  [زر: «عرض الكل»]
  [شريط بطاقات أفقي]

[قسم: «وصل حديثًا»]
  [زر: «عرض الكل»]
  [شريط بطاقات أفقي]

[قسم: «الأعلى تقييمًا»]
  [زر: «عرض الكل»]
  [شريط بطاقات أفقي]

[قسم: «اقتراحات مناسبة لك»]
  [يظهر للمستخدم المسجل]
  [شريط بطاقات المنتجات]
  [حالة تسجيل الدخول إن لم يكن مسجلًا]

[قسم: «متاجر عسلكم»]
  [زر: «عرض المتاجر»]
  [بطاقات المتاجر]
```

## 7.2 بطاقة المنتج المختصرة

```text
[بطاقة منتج مربعة]
  [صورة المنتج 1:1]
  [زر الحفظ الصغير]
  [اسم المنتج]
  [الفئة أو التصنيف الفرعي]
  [السعر + العملة]
  [نجوم التقييم]
  [عدد المراجعات]
  [حالة التوفر]
  [اسم المتجر عند الحاجة]
```

الضغط على البطاقة يفتح تفاصيل المنتج. زر الحفظ ينفذ الحفظ أو يطلب الدخول، ويغيّر حالته بصريًا عند النجاح.

## 7.3 بطاقة المتجر المختصرة

```text
[بطاقة متجر]
  [غلاف أو شعار المتجر]
  [اسم المتجر]
  [اسم التاجر إن كان عامًا]
  [المنطقة]
  [عدد المتابعين]
  [متوسط التقييم]
  [عدد المنتجات]
  [زر فتح المتجر]
```

عند اختيار تصنيف ينتقل المستخدم إلى البحث مع تطبيق التصنيف، وتظهر المنتجات في نفس بطاقات 1:1.

# 9. شاشة البحث والتصفية

## 9.1 الشاشة الأساسية

```text
[شريط أعلى]
  [زر الرجوع]
  [حقل البحث: «ابحث عن منتج أو متجر»]
  [زر مسح]

[صف الإجراءات]
  [زر الفلاتر]
  [زر الترتيب]
  [عدد النتائج]

[نتائج البحث]
  [بطاقة منتج]
  [بطاقة منتج]
  [بطاقة متجر عند البحث عن المتاجر]

[حالة قبل البحث]
  [أيقونة بحث]
  [النص: «اكتب ما تبحث عنه»]

[حالة لا نتائج]
  [أيقونة]
  [النص: «لم نعثر على نتائج مطابقة»]
  [زر مسح الفلاتر]
  [زر تحديث]
```

## 9.2 نافذة الفلاتر

```text
[نافذة: «الفلاتر»]
[زر إغلاق]

[قسم الموقع]
  [قائمة محافظة أو منطقة]
  [قائمة مديرية أو منطقة فرعية]
  [زر مسح الموقع]

[قسم السعر]
  [حقل الحد الأدنى]
  [حقل الحد الأعلى]
  [عملة السعر]

[قسم المنتج]
  [نوع المنتج]
  [التصنيف]
  [التصنيف الفرعي]
  [الجودة]
  [الوزن أو الحجم]
  [حالة التوفر]

[قسم المتجر]
  [اختيار متجر محدد عند الحاجة]

[الأزرار]
  [زر: «تطبيق الفلاتر»]
  [زر: «مسح الكل»]
  [زر: «إلغاء»]
```

كل قائمة مرجعية تسمح بالاختيار من القيم المتاحة، وتقبل البحث أو الكتابة عندما تكون القيمة محلية أو غير موجودة في القائمة.

## 9.3 نافذة الترتيب

```text
[العنوان: «ترتيب النتائج»]
[الأكثر مشاهدة]
[الأحدث]
[الأعلى تقييمًا]
[السعر من الأقل إلى الأعلى]
[السعر من الأعلى إلى الأقل]
[الأقرب أو حسب المنطقة]
[زر تطبيق]
```

# 11. صفحة تفاصيل المنتج

## 11.1 رأس المنتج والمعرض

```text
[شريط أعلى: «تفاصيل المنتج»]
  [زر الرجوع]
  [زر مشاركة]

[معرض المنتج 1:1]
  [الصورة الرئيسية المربعة]
  [الصور التالية المربعة]
  [زر الصورة السابقة]
  [زر الصورة التالية]
  [مؤشرات عدد الصور]

[اسم المنتج]
[التقييم بالنجوم]
[عدد المراجعات]
[عدد الإعجابات]
```

## 11.2 بطاقة القرار

```text
[بطاقة القرار]
  [السعر + العملة]
  [حالة التوفر]
  [خيارات التوصيل]
```

# 24. مصفوفة الحالات المشتركة لكل صفحة

| الحالة | العناصر النصية المطلوبة |
|---|---|
| تحميل أولي | مساحة تحميل، نص «جارٍ تحميل البيانات»، عدم عرض أزرار متضاربة. |
| نجاح مع بيانات | المحتوى الكامل، الأزرار الفعالة، العدادات، وحالة المصدر عند الحاجة. |
| نجاح بلا بيانات | أيقونة، عنوان فارغ، شرح، زر تحديث أو إجراء بديل. |
| فشل قابل لإعادة المحاولة | سبب عربي، زر إعادة المحاولة، إبقاء الإدخال الذي لم يُرسل. |
| فشل صلاحية | شرح أن الحساب لا يملك الصلاحية، زر رجوع أو فتح المسار الصحيح. |
| حفظ جارٍ | تعطيل الزر المكرر، مؤشر داخل الزر، منع الإرسال المزدوج. |
| حفظ ناجح | رسالة نجاح، تحديث فوري للعنصر، إعادة قراءة هادئة من المصدر. |
| حفظ pending | عرض النتيجة لصاحبها أو التاجر المسموح، وسم صادق «قيد المراجعة». |
| صورة غير موجودة | مساحة صورة موحدة، أيقونة بديلة، زر + أو كاميرا صغير. |
| صورة فاشلة | fallback بصري، رسالة فشل، زر إعادة الرفع أو التغيير. |
| جلسة منتهية | نافذة دخول، حفظ المدخلات الممكنة، عدم فقدان الصفحة بلا تفسير. |
| مصدر غير متاح | رسالة اتصال، زر تحديث، عدم تقديم بيانات تجريبية على أنها حقيقية. |
