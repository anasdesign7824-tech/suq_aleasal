# Phase 7 — لوحة Admin المحلية

## الهدف

إنشاء لوحة إدارة ويب عربية RTL باسم **عسلكم**، تعمل من Demo Data Layer ولا تتصل بـ Supabase أثناء العرض أو الاختبار. تدعم اللوحة نظرة تشغيلية والكتالوج والمتاجر وطلبات التواصل، وتوضح حدود Demo صراحة.

## التصميم

تطبق اللوحة فلسفة «دار العسل التحريرية»: شريط تحكم بني داكن في اليمين، مساحة بيانات عاجية، ذهب عسلكم للأفعال والحالات الحاسمة، وموجز قرار عملي قبل بيانات الكتالوج. تستخدم الأصول المرجعية للشعار والخط، وتستخدم أصولًا مولدة مخصصة كزخارف سياقية لا كبديل عن الشعار المرجعي.

## نطاق Demo

تقرأ الواجهة Demo Catalog المتولد من Honey Master وتعرض 30 منتجًا و3 متاجر وطلبات تواصل تجريبية. لا تحتوي البيانات على مراجعات أو تقييمات أو أعداد مراجعات مصطنعة. لا تُفعّل أزرار الواجهة أي فعل إنتاجي؛ تظهر رسالة Demo واضحة بدلًا من ذلك.

## بوابة القبول

تشمل البوابة فحص TypeScript وProduction build، وفحص بصري لسطح المكتب والهاتف، ومراجعة مستقلة للأسلوب، ثم تطبيق التعديلات المرئية الناتجة وتوثيقها قبل الالتزام البرمجي.
