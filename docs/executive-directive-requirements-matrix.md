## Immediate scope boundary

The current work package is **Customer App Web + APK**, including shared Flutter contracts, Demo mode, customer-facing merchant/public profile and Demo merchant conversion where required for the customer journey. **Admin Web, Supabase/RLS forensic audit, Landing/Cloudflare, and full system production acceptance remain subsequent packages** and must not be silently mixed into this package.
