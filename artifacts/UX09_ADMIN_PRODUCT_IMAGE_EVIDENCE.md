# UX-09 — صورة المنتج في لوحة الإدارة

## ما تغير

كان جدول الكتالوج الإداري يعرض أيقونة سداسية ثابتة حتى عندما تكون صورة المنتج محفوظة في `product_images`. أضيف `ProductThumb` يعرض أول صورة حقيقية بمربع 1:1، ويعود إلى fallback عسلكم إذا لم توجد الصورة أو فشل تحميلها. لم يتغير مصدر البيانات أو الحذف أو التعديل أو صلاحيات الإدارة.

## البوابات

| البوابة | النتيجة |
|---|---|
| TypeScript `tsc --noEmit` | PASS |
| Vitest | PASS — 8 ملفات / 47 اختبارًا |
| Vite build | PASS |
| تحذير Vite | chunk رئيسي أكبر من 500KB؛ تحذير حجم فقط |

## الحدود

هذا الإصلاح يخص صورة المنتج داخل جدول الإدارة. توحيد تفاصيل المنتج الكاملة داخل الإدارة سيأتي بعد تثبيت عقد الكيان المشترك، ولا توجد بيانات وهمية أو روابط صور جديدة.
