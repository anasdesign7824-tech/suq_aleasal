# UX-01 — إعادة ترتيب الملف الشخصي

## النطاق

أُعيد ترتيب `ProfileScreen` دون تغيير عقد المصادقة أو repository أو وجهات التنقل. أزيل تكرار الشعار من الملف المصادق عليه لأن رأس الملف يعرض هوية المستخدم أصلًا، وبقي الشعار في حالة الزائر. جُمعت أفعال الملف في قسمين بصريين: `نشاطك` للمحفوظات والمتابعات والمراسلات والإشعارات، و`الحساب والمساعدة` للإعدادات والدعم.

## السلوك المحفوظ

| المسار | الحالة |
|---|---|
| الزائر يرى تسجيل الدخول وإنشاء الحساب | محفوظ |
| حالة فشل مزامنة الجلسة لا تظهر كحساب وهمي | محفوظ |
| تعديل الملف الشخصي | محفوظ |
| طلباتي | محفوظ |
| مساحة المتجر/لوحة التاجر | محفوظ |
| تسجيل الخروج وحذف الحساب | محفوظ |
| المحفوظات والمتاجر المتابَعة والمراسلات والإشعارات والدعم | محفوظة مع ترتيب أوضح |
