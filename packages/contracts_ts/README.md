# TypeScript Contracts

موضع العقود النوعية لمشروعي Web عند الحاجة، خصوصًا لوحة Admin وصفحة Landing إذا احتاجت بيانات ديناميكية لاحقًا. يجب أن تحافظ هذه العقود على التطابق الدلالي مع عقود Dart في `packages/contracts_dart`، دون فرض TypeScript على تطبيق Flutter.

لا توجد Feature مكتملة في هذه المرحلة؛ هذا الموضع يثبت الحد المعماري للعقود المستقبلية.
