# Dart Contracts

موضع العقود النوعية الخاصة بتطبيق Flutter/Dart. لا يُفرض TypeScript على التطبيق الجوال. يجب أن تطابق هذه العقود دلاليًا عقود مشاريع Web عند وجود نفس الكيان أو الحالة، مع اختلاف لغة التنفيذ فقط.

لا توجد Feature مكتملة في هذه المرحلة؛ هذا الموضع يثبت الحد المعماري للعقود المستقبلية.
