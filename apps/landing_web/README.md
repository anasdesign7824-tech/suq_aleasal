# عسلكم — Landing Web

Landing عامة عربية RTL لمنصة **عسلكم — منصة العسل اليمني**. الواجهة مبنية كملفات static مستقلة يمكن معاينتها مباشرة أو نشرها على Cloudflare Pages من مجلد `apps/landing_web`.

## الملفات

- `index.html`: بنية الصفحة، الهوية، الأقسام، SEO/Open Graph، وقسم الإشعار.
- `styles.css`: نظام التصميم المتجاوب بألوان عسلكم وحالات reduced-motion.
- `app.js`: التمرير، reveal animation، السنة الحالية، ونموذج اهتمام محلي صريح.

## التشغيل المحلي

من هذا المجلد يمكن تشغيل خادم ملفات static بأي خادم معتمد، مثل:

```text
npx serve . -l 8788
```

ثم فتح `http://127.0.0.1:8788`.

## النشر

النشر العام لم يُنفذ بعد؛ يحتاج حساب Cloudflare Pages مصرحًا به ومشروعًا معتمدًا. لا يحتوي هذا المسار على أسرار أو API keys. شعار الواجهة الخارجية يُحمّل من تخزين الأصول، ولا تُوضع ملفات الوسائط الكبيرة داخل الحزمة.

## حدود التكامل الحالية

قسم التحميل لا يعرض رابط APK غير معتمد؛ يعرض نموذج اهتمام محليًا إلى أن يُثبت artifact نهائي ورابط تنزيل عام. لا يدعي النموذج إرسال بريد أو حفظًا في Backend، ولا تُستخدم بيانات منتجات أو متاجر وهمية.
