# عسلكم — Landing Web

الصفحة التسويقية العامة لمنصة **عسلكم — منصة العسل اليمني**. الاسم الهندسي الداخلي للمسار هو `landing_web` ضمن `Souq Al Assal`، والواجهة عربية RTL.

## النطاق المرحلي

في Phase 1 يُثبت هذا المسار كحد مستقل للصفحة العامة فقط. ستُبنى لاحقًا بعناصر التسويق، معلومات المنصة، دعوات تحميل التطبيق، SEO وOpen Graph، وتُهيأ للنشر على Cloudflare بعد المعاينة والموافقة. لا تُستخدم لوحة الإدارة أو تطبيق الجوال كمصدر معماري للصفحة، ولا يوجد نشر نهائي في هذه المرحلة.
