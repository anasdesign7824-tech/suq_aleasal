# عسلكم — Admin Web

لوحة الإدارة المحلية لمنصة **عسلكم**. الاسم الهندسي الداخلي للمشروع هو `admin_web` ضمن `Souq Al Assal`، والواجهة عربية RTL.

## النطاق المرحلي

في Phase 1 يُثبت هذا المسار كحد مستقل للوحة الإدارة فقط. ستُبنى لاحقًا بصلاحيات وأدوار وسجل تدقيق، وتستخدم عقود TypeScript عند الحاجة، مع اتصال الإنتاج بـ Supabase خلف طبقات البيانات وليس من مكونات الواجهة مباشرة.

تشغيل اللوحة محليًا هو القرار المعتمد. لا يوجد نشر عام لها ضمن نطاق المشروع الحالي.
